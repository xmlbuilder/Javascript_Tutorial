# 배열 기본 개념
자바스크립트 배열(Array) 기본 개념을 깔끔하게 정리.

## 🗂️ 배열 생성 방법
### 자바스크립트에서 배열을 만드는 방법은 크게 두 가지가 있습니다:
- Array 생성자 사용
  - new Array() 문법으로 배열을 생성.
  - 잘 쓰이지는 않고, 특별히 배열 길이를 지정할 때 사용.
```javascript
var data1 = new Array('Sample1', 'Sample2', 'Sample3', 'Sample4');
```


- 배열 리터럴 사용
  - 가장 일반적이고 직관적인 방식.
  - 권장되는 방법.

```javascript
var data2 = ['Sample1', 'Sample2', 'Sample3', 'Sample4'];
```      

## 🔍 typeof와 constructor
- typeof 배열 → 항상 "object"  
  (자바스크립트에서 배열은 객체의 한 종류이기 때문)
- 배열.constructor === Array → true  
  (배열은 Array 생성자로 만들어짐)
- 배열.constructor === Object → false  
  (배열은 객체이긴 하지만, 일반 객체와는 다름)

## ✅ 배열 판별 방법
배열인지 확인하는 가장 안전한 방법은 Array.isArray() 입니다.
```javascript
Array.isArray([1, 2]); // true
Array.isArray({ a: 1, b: "model" }); // false
```

- 객체와 배열을 구분할 때 유용.
- typeof만으로는 배열과 객체를 구분할 수 없으므로 Array.isArray()를 사용해야 함.

## 📌 정리 포인트
- 배열은 객체(Object)의 특별한 형태 → typeof 결과는 "object".
- 배열 생성은 new Array()보다 [] 리터럴 방식이 더 직관적이고 권장됨.
- 배열 판별은 Array.isArray()를 사용해야 확실함.
