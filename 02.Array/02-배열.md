# 배열
아래는 JavaScript에서의 **배열(Array) 선언 방식과 다중 배열(Nested Array)** 에 대한 정리입니다.  
예제와 함께 표로 깔끔하게 정리.

## ✅ 배열 선언 방식
```javascript
var data1 = new Array('Sample1', 'Sample2', 'Sample3', 'Sample4');
var data2 = ['Sample1', 'Sample2', 'Sample3', 'Sample4'];
```
- new Array(...) 방식은 생성자 호출
- [...] 리터럴 방식이 더 간결하고 일반적으로 권장됨

## 📊 선언 방식 비교표
| 선언 방식                  | 설명                          | 예시 결과                                 |
|---------------------------|-------------------------------|--------------------------------------------|
| new Array(...)            | 생성자 방식                   | ['Sample1', 'Sample2', 'Sample3', 'Sample4'] |
| [...]                     | 리터럴 방식 (추천)            | ['Sample1', 'Sample2', 'Sample3', 'Sample4'] |


## ✅ 다중 배열 (Nested Array)

```javascript
var data = [
    'Sample1',
    'Sample2',
    ['Sample3', 'Sample4']
];

console.log(data[0]);      // "Sample1"
console.log(data[2][1]);   // "Sample4"
```

- 배열 안에 또 다른 배열을 포함 → 다차원 구조
- data[2]는 배열 ['Sample3', 'Sample4']
- data[2][1]은 "Sample4"에 접근

## 📊 다중 배열 구조 요약
| 접근 표현식     | 설명                          | 결과 값     |
|----------------|-------------------------------|-------------|
| data[0]        | 첫 번째 요소                   | "Sample1"   |
| data[2]        | 세 번째 요소 (배열)            | ['Sample3', 'Sample4'] |
| data[2][1]     | 다중 배열의 두 번째 요소       | "Sample4"   |

## ✅ 실전 팁
- 배열은 length 속성을 통해 크기 확인 가능
- `Array.isArray(obj)` 로 배열 여부 확인
- 다중 배열은 for, forEach, map 등으로 반복 처리 가능
- JSON 구조와 유사하므로 API 응답 처리에도 자주 사용됨

# 순회

배열 메서드와 다차원 배열 순회는 실전에서 매우 자주 사용되는 핵심 기술입니다.  
아래에 주요 메서드와 다차원 배열 처리 방법을 예제와 함께 정리했습니다.

## ✅ 자주 쓰는 배열 메서드 요약
| 메서드      | 설명                                      | 예시 결과                        |
|-------------|-------------------------------------------|----------------------------------|
| push()      | 배열 끝에 요소 추가                        | [1,2].push(3) → [1,2,3]          |
| pop()       | 배열 끝 요소 제거                         | [1,2,3].pop() → [1,2]            |
| shift()     | 배열 앞 요소 제거                         | [1,2,3].shift() → [2,3]          |
| unshift()   | 배열 앞에 요소 추가                       | [2,3].unshift(1) → [1,2,3]       |
| map()       | 각 요소에 함수 적용 → 새 배열 반환        | [1,2].map(x => x*2) → [2,4]      |
| filter()    | 조건 만족 요소만 추출 → 새 배열 반환      | [1,2,3].filter(x => x>1) → [2,3] |
| forEach()   | 각 요소에 대해 함수 실행 (반환 없음)      | [1,2].forEach(x => console.log(x)) |
| reduce()    | 누적 계산                                 | [1,2,3].reduce((a,b)=>a+b) → 6   |


- 🔍 map()과 filter()는 원본 배열을 변경하지 않고 새 배열을 반환합니다.
- forEach()는 반환값이 없고 단순 반복에 사용됩니다.


## ✅ 다차원 배열 순회
### 🔹 2차원 배열 예시
```javascript
const matrix = [
  [1, 2],
  [3, 4],
  [5, 6]
];

// 중첩 for문
for (let i = 0; i < matrix.length; i++) {
  for (let j = 0; j < matrix[i].length; j++) {
    console.log(matrix[i][j]);
  }
}
```

### 🔹 forEach로 순회
```javascript
matrix.forEach(row => {
  row.forEach(cell => {
    console.log(cell);
  });
});
```

### 🔹 map + flat
```javascript

const flat = matrix.flat(); // [1,2,3,4,5,6]
const doubled = flat.map(x => x * 2); // [2,4,6,8,10,12]
```

- 🔍 flat()은 ES2019부터 지원되며, 중첩 배열을 평탄화합니다.


## ✅ 실전 예제: filter + map 조합
```javascript
const students = [
  { name: "JungHwan", score: 85 },
  { name: "Mina", score: 92 },
  { name: "Taeho", score: 76 }
];

const passed = students
  .filter(s => s.score >= 80)
  .map(s => s.name);

console.log(passed); // ["JungHwan", "Mina"]
```


## ✅ 핵심 요약
- push/pop/shift/unshift → 배열에 요소 추가/제거
- map/filter/reduce → 함수형 프로그래밍에 적합
- 다차원 배열은 중첩 반복문 또는 flat()으로 처리
- map + filter 조합은 조건 기반 데이터 추출에 매우 유용

# 정렬 / 검색

이제 배열의 **정렬(sort)** 과 **검색(find, includes)** 까지 확장해서 정리.  
실전에서 자주 쓰이는 패턴과 주의할 점을 함께 담았습니다.

## ✅ 배열 정렬 (sort)
### 🔹 기본 사용법
```javascript
const arr = [3, 1, 4, 2];
arr.sort();
console.log(arr); // [1, 2, 3, 4]
```

- 기본적으로 문자열 기준으로 정렬합니다.
- 숫자 배열을 정렬할 때는 비교 함수를 반드시 지정해야 합니다.
### 🔹 숫자 정렬
```javascript
const nums = [10, 2, 30];
nums.sort((a, b) => a - b); // 오름차순
console.log(nums); // [2, 10, 30]
```
```javascript
nums.sort((a, b) => b - a); // 내림차순
console.log(nums); // [30, 10, 2]
```

### 🔹 객체 배열 정렬
```javascript
const people = [
  { name: "JungHwan", age: 30 },
  { name: "Mina", age: 25 },
  { name: "Taeho", age: 35 }
];

people.sort((a, b) => a.age - b.age);
console.log(people);
// [{Mina,25}, {JungHwan,30}, {Taeho,35}]
```


## ✅ 배열 검색
### 🔹 find()
- 조건을 만족하는 첫 번째 요소 반환

```javascript
const arr = [5, 12, 8, 130, 44];
const found = arr.find(x => x > 10);
console.log(found); // 12
```

### 🔹 includes()
- 배열에 특정 값이 존재하는지 확인 (true/false 반환)
```javascript
const arr = [1, 2, 3, 4];
console.log(arr.includes(3)); // true
console.log(arr.includes(5)); // false
```

### 🔹 indexOf()
- 특정 값의 인덱스 반환 (없으면 -1)
```javascript
const arr = ["apple", "banana", "cherry"];
console.log(arr.indexOf("banana")); // 1
console.log(arr.indexOf("grape"));  // -1
```


## 📊 배열 정렬 & 검색 요약표
| 메서드       | 설명                                   | 예시 결과                          |
|--------------|----------------------------------------|------------------------------------|
| sort()       | 기본은 문자열 기준 정렬                | [3,1,4] → [1,3,4]                  |
| sort(fn)     | 비교 함수로 숫자/객체 정렬 가능        | [10,2,30] → [2,10,30]              |
| find(fn)     | 조건 만족 첫 요소 반환                 | [5,12,8].find(x>10) → 12           |
| includes(val)| 배열에 값 존재 여부 반환               | [1,2,3].includes(2) → true         |
| indexOf(val) | 값의 인덱스 반환 (없으면 -1)           | ["a","b"].indexOf("b") → 1         |


## ✅ 실전 팁
- `sort()` 는 원본 배열을 변경합니다 → 필요하다면 .slice()로 복사 후 정렬
- `find()` 는 첫 번째 요소만 반환, 여러 개 찾으려면 filter()
- **includes()는 엄격한 비교(===)** 를 사용 → 타입이 다르면 false
- 문자열 검색 시 대소문자 무시하려면 .toLowerCase()와 함께 사용


# some / every/ flat / findIndex
이제 배열의 **고급 메서드 (some, every, flat, findIndex)** 까지 정리. 
실전 예제와 함께 표로 깔끔하게 정리했습니다.

## ✅ 배열 고급 메서드
### 🔹 some()
- 배열 요소 중 하나라도 조건을 만족하면 true 반환
```javascript
const arr = [1, 2, 3, 4];
console.log(arr.some(x => x > 3)); // true
console.log(arr.some(x => x > 10)); // false
```


### 🔹 every()
- 배열 요소가 모두 조건을 만족해야 true 반환
```javascript
const arr = [2, 4, 6];
console.log(arr.every(x => x % 2 === 0)); // true
console.log(arr.every(x => x > 3));       // false
```


### 🔹 flat()
- 중첩 배열을 평탄화 (ES2019부터 지원)
```javascript
const arr = [1, [2, 3], [4, [5, 6]]];
console.log(arr.flat());     // [1, 2, 3, 4, [5, 6]]
console.log(arr.flat(2));    // [1, 2, 3, 4, 5, 6]
```


### 🔹 findIndex()
- 조건을 만족하는 첫 번째 요소의 인덱스 반환
```javascript
const arr = [5, 12, 8, 130, 44];
console.log(arr.findIndex(x => x > 10)); // 1 (12의 인덱스)
console.log(arr.findIndex(x => x > 200)); // -1 (없음)
```


## 📊 배열 고급 메서드 요약표
| 메서드       | 설명                                   | 예시 결과                          |
|--------------|----------------------------------------|------------------------------------|
| some(fn)     | 하나라도 조건 만족 → true              | [1,2,3].some(x>2) → true           |
| every(fn)    | 모두 조건 만족 → true                  | [2,4,6].every(x%2===0) → true      |
| flat(depth)  | 중첩 배열 평탄화 (depth 지정 가능)     | [1,[2,3]].flat() → [1,2,3]         |
| findIndex(fn)| 조건 만족 첫 요소 인덱스 반환          | [5,12,8].findIndex(x>10) → 1       |



## ✅ 실전 팁
- some() → 조건을 만족하는 요소가 있는지 빠르게 확인할 때 유용
- every() → 모든 요소가 조건을 만족하는지 검증할 때 사용 (예: 유효성 검사)
- flat() → API 응답에서 중첩 배열을 다룰 때 매우 편리
- findIndex() → 조건에 맞는 요소 위치를 찾을 때 사용, 없으면 -1 반환

# reduceRight / fill / copyWithin
이제 배열 변환 고급 메서드인 reduceRight, fill, copyWithin을 정리.  
이들은 배열을 다루는 데 있어 조금 더 특수한 상황에서 유용하게 쓰입니다.

## ✅ reduceRight()
- reduce()와 동일하지만 오른쪽 → 왼쪽으로 순회하며 누적 계산
- 누적 연산이나 역순 처리에 활용
```javascript
const arr = [1, 2, 3, 4];
const result = arr.reduceRight((acc, cur) => acc - cur);
console.log(result); // ((4-3)-2)-1 = -2
```


## ✅ fill()
- 배열의 특정 구간을 고정된 값으로 채움
- 원본 배열을 변경
```javascript
const arr = [1, 2, 3, 4];
arr.fill(0, 1, 3); // index 1~2를 0으로 채움
console.log(arr); // [1, 0, 0, 4]
```
```javascript
const arr2 = new Array(5).fill(7);
console.log(arr2); // [7, 7, 7, 7, 7]
```


## ✅ copyWithin()
- 배열의 일부를 다른 위치에 복사하여 덮어씀
- 원본 배열을 변경
```javascript
const arr = [1, 2, 3, 4, 5];
arr.copyWithin(0, 3); // index 3부터 끝까지 → index 0부터 덮어쓰기
console.log(arr); // [4, 5, 3, 4, 5]
```
```javascript
const arr2 = [10, 20, 30, 40, 50];
arr2.copyWithin(1, 3, 5); // index 3~4 → index 1부터 덮어쓰기
console.log(arr2); // [10, 40, 50, 40, 50]
```

## 📊 배열 변환 고급 메서드 요약표
| 메서드          | 설명                                   | 예시 결과                                |
|-----------------|----------------------------------------|------------------------------------------|
| reduceRight(fn) | 오른쪽 → 왼쪽으로 누적 계산            | [1,2,3,4].reduceRight((a,b)=>a-b) → -2   |
| fill(val,s,e)   | 특정 구간을 지정 값으로 채움           | [1,2,3,4].fill(0,1,3) → [1,0,0,4]        |
| copyWithin(t,s,e)| 배열 일부를 복사해 다른 위치에 덮어씀 | [1,2,3,4,5].copyWithin(0,3) → [4,5,3,4,5]|



## ✅ 핵심 포인트
- reduceRight → reduce와 동일하지만 방향이 반대
- fill → 초기화, 특정 값으로 배열 채우기
- copyWithin → 배열 내부에서 값 복사/덮어쓰기 (원본 변경)

# 배열 생성/변환 메소드

배열 **생성/변환 메서드 (Array.from, Array.of, Array.isArray)** 까지 정리.  
이들은 배열을 만들거나 확인할 때 자주 쓰이는 기본기입니다.

## ✅ Array.from()
- 유사 배열 객체(array-like) 또는 **이터러블(iterable)** 을 배열로 변환
- 두 번째 인자로 매핑 함수를 줄 수 있음
```javascript
console.log(Array.from('Hello')); 
// ['H','e','l','l','o']
```
```javascript
console.log(Array.from([1, 2, 3], x => x * 2)); 
// [2, 4, 6]
```
```javascript
const set = new Set([1, 2, 3]);
console.log(Array.from(set)); 
// [1, 2, 3]
```  


## ✅ Array.of()
- 전달된 인자를 그대로 요소로 갖는 배열 생성
- new Array()와 달리 인자 개수에 따라 동작이 달라지지 않음
```javascript
console.log(Array.of(7)); 
// [7]
```
```javascript
console.log(Array.of(1, 2, 3)); 
// [1, 2, 3]
```
```javascript
console.log(new Array(7)); 
// 길이가 7인 빈 배열
```


## ✅ Array.isArray()
- 주어진 값이 배열인지 여부를 boolean으로 반환
```javascript
console.log(Array.isArray([1, 2, 3])); 
// true
```
```javascript
console.log(Array.isArray('Hello')); 
// false
```
```javascript
console.log(Array.isArray({ a: 1 })); 
// false
```

## 📊 배열 생성/변환 메서드 요약표
| 메서드           | 설명                                      | 예시 결과                          |
|------------------|-------------------------------------------|------------------------------------|
| Array.from(obj)  | 유사 배열/이터러블 → 배열 변환             | Array.from('Hi') → ['H','i']       |
| Array.of(...val) | 인자를 그대로 요소로 갖는 배열 생성        | Array.of(1,2,3) → [1,2,3]          |
| Array.isArray(x) | 값이 배열인지 여부 확인 (true/false)       | Array.isArray([1,2]) → true        |



## ✅ 핵심 포인트
- Array.from → 문자열, Set, Map 등 이터러블을 배열로 변환할 때 유용
- Array.of → 단일 숫자 인자로도 안전하게 배열 생성 가능
- Array.isArray → 타입 체크 시 필수 (특히 객체와 배열 구분할 때)
