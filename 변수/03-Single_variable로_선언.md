## [❌ 나쁜 예시] 여러 줄에 var 반복 선언
────────────────────────────────────────────
```javascript
function func() {
    var a = 1;
    var b = 2;
    var sum = a + b;
    var myobject = {};
    var i;
    var j;
    // function body...
}
```
- 문제점:
    - `var`가 반복되어 가독성이 떨어짐
    - 유지보수 시 실수 가능성 증가
    - 선언 위치가 분산되어 구조 파악이 어려움

## [✅ 좋은 예시] Comma를 통한 Single var 선언
────────────────────────────────────────────
```javascript
function func() {
    var a = 1,
        b = 2,
        sum = a + b,
        myobject = {},
        i,
        j;
    // function body...
}
```
- 장점:
    - 선언이 한 곳에 집중되어 가독성 향상
    - 변수 초기화 상태를 한눈에 파악 가능
    - 유지보수 및 리팩토링에 유리

## [📌 권장 스타일]
────────────────────────────────────────────
- 함수 내부에서는 `let`, `const`를 사용
- `var`는 레거시 코드나 호환성 목적 외에는 지양
- 여러 변수는 한 줄에 comma로 묶어 선언
- 선언과 초기화를 명확히 구분

## 예:
```javascript
const PI = 3.14;
let x = 0, y = 0, z;
```
## [🚫 주의사항]
────────────────────────────────────────────
- 선언 없이 변수 사용 금지 (예: i = 3;)
- 암묵적 전역은 글로벌 객체에 등록되어 예기치 않은 동작 유발
- 항상 명시적으로 선언할 것
