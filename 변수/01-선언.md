# 📘 JavaScript 변수 선언 정리
## 1. 변수 선언 방식 비교

| 키워드   | 블록 스코프 | 재할당 가능 | 재선언 가능 | 호이스팅 | 글로벌 객체 등록 |
|----------|-------------|--------------|--------------|-----------|-------------------|
| `var`    | ❌ (함수 스코프) | ✅           | ✅           | ✅ (초기화 X) | ✅ (`window.i`)   |
| `let`    | ✅           | ✅           | ❌           | ✅ (초기화 X) | ❌                |
| `const`  | ✅           | ❌           | ❌           | ✅ (초기화 X) | ❌                |



## 2. 선언 없이 사용하는 경우
```javascript
i = 3; // ❌ 선언 없이 사용
```
- i는 전역 객체의 속성으로 등록됨
- 브라우저에서는 window.i, Node.js에서는 global.i
- 이미지에서 보인 i: 3은 이런 방식으로 생긴 전역 속성입니다

## 3. 예제 비교
```javascript
var msg = "Hello World"; // 함수 스코프, 글로벌 객체에 등록됨
var j;                   // 선언만, 값은 undefined
i = 3;                   // ❌ 글로벌 객체에 i 등록됨
var name1 = "Jeong", name2 = "Junghwan"; // 둘 다 글로벌 등록

console.log(msg);    // Hello World
console.log(j);      // undefined
console.log(i);      // 3
console.log(name1);  // Jeong
console.log(name2);  // Junghwan
```
→ i는 선언 없이 사용되어 글로벌 객체에 등록됨

## 4. 글로벌 객체와 변수
이미지에서 보인 구조는 Node.js 또는 브라우저의 글로벌 객체입니다. 주요 특징:
- `i`: 3 → 선언 없이 할당된 변수
- `setTimeout`, `fetch`, `crypto`, `atob`, `btoa` 등은 글로벌 API
- [Getter], [Getter/Setter] → 프로퍼티 접근자
- [Circular *1] → 자기 자신을 참조하는 구조

## 5. 권장 사항
- ✅ 항상 let 또는 const를 사용하세요
- ✅ 선언 없이 변수 사용 금지 (i = 3 ❌)
- ✅ const는 불변 값에, let은 변경 가능한 값에
- ✅ var는 레거시 코드 외에는 사용 지양

## 6. 안전한 선언 예시
```javascript
const name = "Junghwan"; // 불변
let count = 0;           // 변경 가능
count += 1;
```
