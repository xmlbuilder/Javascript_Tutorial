# 형 변환

**JavaScript의 형변환(Type Conversion)** 에 대한 정리입니다.  
명시적 형변환과 암묵적 형변환의 차이, 그리고 typeof 결과까지 함께 설명합니다.

## 📘 JavaScript 형변환(Type Conversion) 정리
### ✅ 1. 명시적 형변환 (Explicit Conversion)
```javascript
console.log(typeof String(123));       // "string"
console.log(typeof Boolean(-1));       // "boolean"
console.log(typeof new String(123));   // "object"
````

| 표현식             | 결과 값 또는 타입     |
|--------------------|------------------------|
| String(123)        | "123" (문자열 리터럴) |
| Boolean(-1)        | true (불리언 값)       |
| new String(123)    | typeof "object"        |


- 🔍 new String()은 문자열 객체를 생성하므로 typeof 결과가 "object" 입니다.
- 반면 String()은 문자열 리터럴을 반환하므로 "string"입니다.


## ✅ 2. 암묵적 형변환 (Implicit Conversion)
```rust
console.log(typeof (15 + ''));         // "string"
console.log(typeof ('15' - 0));        // "number"
console.log('15' - 0);                 // 15
```

| 표현식        | 결과 값       |
|---------------|----------------|
| 15 + ''       | "15" (문자열)  |
| '15' - 0      | 15 (숫자)      |
| '15' - 0      | 15 (숫자)      |

## ✅ 설명:
- 15 + '' → 숫자 + 문자열 → 문자열 연결 → "15"
- '15' - 0 → 문자열 → 숫자 변환 후 계산 → 15

- 🔍 + 연산자는 문자열이 포함되면 문자열 연결로 동작
- -, *, / 등은 문자열을 숫자로 변환하려 시도함


## ✅ 3. 불리언 변환
```javascript
var value = 1;
console.log(typeof value);     // "number"
console.log(typeof (!value));  // "boolean"
```

| 표현식     | 결과 값 / 타입            |
|------------|---------------------------|
| value = 1  | 1 (number)                |
| !value     | !1 → false (typeof "boolean") |

## ✅ 설명
- value = 1 → 숫자형 원시값 저장 → typeof value는 "number"
- !value → !1 → truthy 값 1을 불리언으로 변환 후 반전 → false
→ typeof (!value)는 "boolean"


## 🔍 !value는 불리언으로 강제 변환 후 반전합니다.


## 📊 요약표 (Markdown ASCII)
| 표현식               | 결과 타입 | 변환 방식     | 설명                                 |
|----------------------|------------|----------------|--------------------------------------|
| `String(123)`        | "string"   | 명시적         | 숫자 → 문자열                        |
| `Boolean(-1)`        | "boolean"  | 명시적         | 음수는 truthy → true                 |
| `new String(123)`    | "object"   | 명시적         | 문자열 객체 생성                     |
| `15 + ''`            | "string"   | 암묵적         | 숫자 + 문자열 → 문자열 연결         |
| `'15' - 0`           | "number"   | 암묵적         | 문자열 → 숫자 변환 후 계산           |
| `!value`             | "boolean"  | 암묵적         | truthy → boolean → 반전              |

## ✅ 핵심 개념
- 명시적 변환: String(), Number(), Boolean() 등 직접 호출
- 암묵적 변환: 연산자(+, -, !)나 조건문에서 자동으로 발생
- typeof는 값의 타입을 문자열로 반환하지만, 객체 생성 시 "object"로 나옴
