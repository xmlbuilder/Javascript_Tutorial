# 상수 선언
JavaScript에서의 상수 선언(Constant Declaration) 개념과 함께, 예제를 기반으로 문서화한 내용입니다:

## 📘 JavaScript에서의 상수 선언 정리
### 1. 🔒 상수란?
- **상수(Constant)** 는 한 번 할당된 값을 변경할 수 없는 변수입니다.
- JavaScript에서는 const 키워드를 사용하여 상수를 선언합니다.
- 상수는 재할당이 불가능하지만, 객체나 배열처럼 참조 타입일 경우 내부 속성은 변경 가능합니다.

### 2. ✅ 기본 상수 선언 예시
```javascript
const PI = 3.14159;
console.log(PI); // 3.14159
```
- PI는 숫자 상수로 선언되었으며, 이후 값을 변경할 수 없습니다.
- PI = 3.14; 와 같이 재할당하면 TypeError가 발생합니다.

### 3. ⚠️ 객체 속성으로 상수처럼 사용하기
```javascript
var Obj = {};
Obj.PI = 1.2;
console.log(Obj.PI); // 1.2
```

- Obj는 var로 선언된 일반 객체입니다.
- Obj.PI는 객체의 속성으로 추가된 값이며, 상수가 아닙니다.
- 즉, Obj.PI = 3.14; 와 같이 언제든지 변경 가능합니다.

### 4. 🛡️ 객체 속성을 상수처럼 보호하려면?
#### 방법 1: const + Object.freeze()
```javascript
const Obj = Object.freeze({
  PI: 3.14159
});

console.log(Obj.PI); // 3.14159
Obj.PI = 3.14;       // 무시됨 (변경되지 않음)
```

- Object.freeze()를 사용하면 객체의 속성을 읽기 전용으로 만들 수 있습니다.
- 단, **얕은 동결(shallow freeze)**이므로 중첩 객체는 보호되지 않습니다.
#### 방법 2: const + getter
```javascript
const Obj = {};
Object.defineProperty(Obj, 'PI', {
  value: 3.14159,
  writable: false,
  configurable: false
});

console.log(Obj.PI); // 3.14159
Obj.PI = 3.14;       // 무시됨
```

- Object.defineProperty()를 사용하면 속성 단위로 쓰기 금지(writable: false) 설정이 가능합니다.

## 📎 요약

| 선언 방식                          | 값 변경 가능 여부 | 적용 대상       | 설명                                      |
|-----------------------------------|-------------------|----------------|-------------------------------------------|
| const PI = 3.14                   | ❌ 불가능          | 변수 자체       | 재할당 불가. 원시 타입 상수 선언에 적합     |
| var Obj = {}; Obj.PI = 1.2        | ✅ 가능            | 객체 속성       | 일반 객체 속성으로, 언제든지 값 변경 가능   |
| Object.freeze()                   | ❌ (얕은 동결)     | 전체 객체       | 객체 전체를 읽기 전용으로 설정 (중첩 객체 제외) |
| Object.defineProperty()           | ❌ (속성 단위)     | 특정 속성       | 속성 단위로 쓰기 금지 설정 가능             |
