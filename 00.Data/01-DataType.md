## 📘 JavaScript 데이터 타입 정리
JavaScript의 데이터 타입은 크게 두 가지로 나뉩니다:
### 1. 🧱 Primitive Type (원시 타입)
- 정의: 값을 그대로 변수에 할당합니다. 복사 시 값 자체가 복사됩니다.
- 특징: 불변(immutable)하며, 메모리 상에 직접 값이 저장됩니다.
- 종류:
  - Number : 숫자형 (예: 42, 3.14)
  - String : 문자열형 (예: "hello")
  - Boolean : 논리형 (true, false)
  - null : 명시적 "없음"을 나타내는 값
  - undefined : 값이 정의되지 않음
- 📌 **값을 그대로 할당**


### 2. 🧠 Reference Type (참조 타입)
- 정의: 변수에는 값이 저장된 주소값이 할당됩니다. 복사 시 주소만 복사되므로 원본이 변경될 수 있습니다.
- 특징: 가변(mutable)하며, 메모리 상에 객체가 저장되고 변수는 그 주소를 참조합니다.
- 종류:
  - Object : 모든 참조 타입의 기본 구조
  - Array : 배열 (예: [1, 2, 3])
  - Function : 함수 (예: function() {})
  - RegExp : 정규 표현식 (예: /abc/)
- 📌 **값이 저장된 주소값을 할당 (참조)**


## 📎 요약 비교

| 구분             | Primitive Type (원시 타입)     | Reference Type (참조 타입)         |
|------------------|-------------------------------|------------------------------------|
| 메모리 저장 방식 | 값 자체를 저장                 | 값이 저장된 주소를 저장 (참조)     |
| 복사 시 동작     | 값 복사                        | 주소 복사 (원본 공유)              |
| 대표 타입        | Number, String, Boolean 등     | Object, Array, Function 등         |
| 변경 가능 여부   | 불변 (immutable)               | 가변 (mutable)                     |
| 특징             | 직접 값을 할당                 | 참조를 통해 값에 접근              |
