# 부동 소수점 문제
JavaScript에서의 부동소수점(Floating Point) 유효 숫자 문제와 그 해결 방안을 문서 형식으로 정리한 내용입니다:

## 📘 JavaScript의 부동소수점 유효 숫자 문제와 해결 방안
### 1. ⚠️ 문제 개요: 부동소수점 연산 오류
JavaScript는 IEEE 754 표준의 64비트 부동소수점 숫자를 사용합니다.  
이로 인해 일부 소수 연산에서 정확한 값이 표현되지 않는 문제가 발생합니다.

#### 예시 코드
```javascript
console.log(0.1 * 3); // 출력: 0.30000000000000004
```
- 0.1은 이진수로 정확히 표현할 수 없는 값입니다.
- 따라서 0.1 * 3은 0.3이 아닌 근사값이 출력됩니다.

### 2. 🔍 원인 분석
- 이진 부동소수점 표현 한계: 0.1은 2진수로 무한 반복되는 값이므로, 메모리에 저장될 때 근사값으로 저장됩니다.
- 연산 누적 오차: 작은 오차가 연산을 거치면서 누적되어 눈에 띄는 차이로 나타납니다.

### 3. ✅ 해결 방안
#### 방법 1: 정수 기반 스케일링
```javascript
console.log((10 * 0.1) * 3 / 10); // 출력: 0.3
```

- 0.1을 10으로 곱해 정수로 만든 후 연산하고 다시 나눕니다.
- 정수 연산을 활용해 오차를 줄이는 방식입니다.
#### 방법 2: .toFixed() 사용
```javascript
let result = (0.1 * 3).toFixed(2); // "0.30"
console.log(result);
```

- 소수점 자리수를 고정하여 문자열로 정확한 표현을 얻습니다.
- 단, 결과는 문자열이므로 숫자 연산에는 다시 parseFloat() 필요.
#### 방법 3: 오차 허용 범위 비교 (EPSILON)
```javascript
let result = 0.1 * 3;
if (Math.abs(result - 0.3) < Number.EPSILON) {
  console.log("거의 같다");
}
```

- Number.EPSILON은 JavaScript에서 표현 가능한 가장 작은 차이를 나타냅니다.
- 실제 값과 기대값의 차이가 매우 작을 경우 "같다"로 간주합니다.

## 4. 📎 요약 비교
| 해결 방법               | 설명                                      | 주의사항                         |
|------------------------|-------------------------------------------|----------------------------------|
| 정수 기반 스케일링     | 정수로 변환 후 연산하여 오차 제거         | 스케일링 기준 주의               |
| toFixed()              | 소수점 자리수 고정하여 문자열로 출력      | 숫자 연산 시 변환 필요           |
| Number.EPSILON 비교    | 오차 허용 범위 내에서 값 비교             | 정확한 비교가 아닌 근사 비교     |



## 5. 🧠 실무 팁
- 금융 계산이나 정밀한 수치 연산이 필요한 경우에는 부동소수점 대신 정수 기반 계산 또는 BigInt / 외부 라이브러리(decimal.js 등) 사용을 고려.
- 테스트 시에는 === 비교보다 Math.abs(a - b) < ε 방식이 더 안전합니다.
