# 지역 변수 은닉화

## 🚗 자동차 게임 시뮬레이션 문서 (지역 변수 은닉 중심)

### 📘 개요
JavaScript 객체와 함수 스코프를 활용하여 자동차의 연료 소비와 이동 거리를 시뮬레이션하는 게임을 설명합니다.  
특히 **지역 변수(wasteFuel)** 를 외부에 노출하지 않고 내부에서만 사용하는 구조를 통해  
**데이터 은닉(data encapsulation)** 을 실현하는 방법을 강조합니다.

### 🔐 지역 변수 은닉이란?
- **지역 변수(local variable)** 는 함수 내부에서 선언되며, 외부에서 접근할 수 없습니다.
- 이는 불필요한 정보 노출을 방지하고, 코드 안정성과 보안성을 높이는 핵심 원칙입니다.
- 자동차 게임 예제에서는 **wasteFuel** 이 `지역 변수` 로 선언되어 외부에서 접근할 수 없습니다.

### 🧩 핵심 코드 구조
```javascript
var car = {
  fuel: 50,       // 공개 속성: 외부에서 접근 가능
  power: 5,       // 공개 속성: 외부에서 접근 가능
  run: function(km) {
    // 지역 변수: 외부에서 접근 불가
    var wasteFuel = km / this.power;

    if (this.fuel < wasteFuel) {
      console.log("연료 부족");
      return;
    }

    this.fuel -= wasteFuel;
    console.log("이동 거리: " + km);
    console.log("남은 연료: " + this.fuel);
  }
};
```      

### ✅ 지역 변수 wasteFuel의 특징
- run 함수 내부에서만 존재
- 외부에서 car.wasteFuel로 접근 불가
- 연료 계산 로직을 외부로부터 보호

### 🧪 실행 예시
```javascript
car.run(10);  // 충분한 연료
car.run(100); // 연료 부족
car.run(250); // 연료 정확히 소진
```

### 출력 예시:
```
이동 거리: 10
남은 연료: 48
연료 부족
이동 거리: 250
남은 연료: 0
```


## 🧠 캡슐화의 장점

| 항목             | 설명                                           | 예시 또는 효과                          |
|------------------|-----------------------------------------------|-----------------------------------------|
| 정보 은닉        | 내부 구현 세부사항을 외부에 노출하지 않음      | 지역 변수 `wasteFuel`은 외부 접근 불가   |
| 유지보수 용이성  | 내부 로직 변경 시 외부 코드에 영향이 적음      | 연료 계산 방식을 바꿔도 인터페이스 동일  |
| 오류 방지        | 외부에서 잘못된 값이나 로직에 접근 불가        | 잘못된 연료 계산식 직접 호출 불가능      |
| 인터페이스 명확화| 필요한 기능만 메서드로 제공하여 사용성 향상    | `run()`, `refuel()` 같은 공개 메서드 제공|
| 보안성 향상      | 중요한 데이터가 보호되어 안정성 확보           | 연료량은 `getFuel()`로만 확인 가능       |

## 📦 확장 아이디어
- 여러 차량 객체 생성하여 경주 시뮬레이션
- run 함수 내부에 더 많은 지역 변수 활용 (예: 누적 거리)
- car 객체를 생성자 함수 또는 클래스 구조로 리팩토링하여 캡슐화 강화

## 📄 요약 테이블
| 요소        | 접근 범위       | 설명                                 |
|-------------|------------------|--------------------------------------|
| fuel        | 외부 접근 가능   | 차량의 현재 연료량                   |
| power       | 외부 접근 가능   | 연비 (1리터당 주행 가능한 거리)      |
| run(km)     | 외부 접근 가능   | 주행 함수, 내부 로직은 은닉됨        |
| wasteFuel   | 내부 접근만 가능 | 지역 변수, 연료 계산에 사용됨        |

# 클래스 기반

아래는 기존 자동차 게임 코드를 **클래스 기반(Class-based)** 으로 리팩토링한 예제입니다.  
이 구조는 **객체 지향 프로그래밍(OOP)** 의 핵심 개념인 **캡슐화(encapsulation)** 를 더 명확하게 표현하며,  
여러 차량 인스턴스를 생성하고 관리하기에도 적합합니다.

## 🚗 클래스 기반 자동차 게임 예제
```javascript
class Car {
  constructor(fuel, power) {
    this.fuel = fuel;   // 연료량 (공개 속성)
    this.power = power; // 연비 (공개 속성)
  }

  run(km) {
    // wasteFuel은 지역 변수로 외부에 노출되지 않음 (캡슐화)
    const wasteFuel = km / this.power;

    if (this.fuel < wasteFuel) {
      console.log("연료 부족");
      return;
    }

    this.fuel -= wasteFuel;
    console.log("이동 거리: " + km);
    console.log("남은 연료: " + this.fuel);
  }
}
```


### 🧪 사용 예시
```javascript
const car1 = new Car(50, 5);  // 연료 50, 연비 5km/L

car1.run(10);   // 충분한 연료
car1.run(100);  // 연료 부족
car1.run(250);  // 연료 정확히 소진
```

### 출력:
```
이동 거리: 10
남은 연료: 48
연료 부족
이동 거리: 250
남은 연료: 0
```


## 🔐 캡슐화 강조 포인트
- wasteFuel은 run 메서드 내부의 지역 변수로 선언되어 외부에서 접근 불가
- fuel과 power는 생성자에서 초기화되며, 필요 시 getter/setter로 제어 가능
- 클래스 구조는 다수의 차량 인스턴스 생성에 유리하며, 확장성이 뛰어남

## 📦 확장 아이디어
- Car 클래스에 name 속성 추가하여 차량 식별
- getFuel() 메서드로 연료 조회, refuel() 메서드로 연료 보충
- Race 클래스를 만들어 여러 차량 간 경주 로직 구현

## 🚗 TypeScript 기반 자동차 클래스
```typescript
class Car {
  private fuel: number;   // 연료량 (외부에서 직접 접근 불가)
  private power: number;  // 연비 (외부에서 직접 접근 불가)

  constructor(fuel: number, power: number) {
    this.fuel = fuel;
    this.power = power;
  }

  public run(km: number): void {

    const wasteFuel: number = km / this.power;

    if (this.fuel < wasteFuel) {
      console.log("연료 부족");
      return;
    }

    this.fuel -= wasteFuel;
    console.log("이동 거리: " + km);
    console.log("남은 연료: " + this.fuel);
  }

  public getFuel(): number {
    return this.fuel;
  }

  public refuel(amount: number): void {
    this.fuel += amount;
    console.log("연료 보충됨. 현재 연료: " + this.fuel);
  }
}
```


### 🧪 사용 예시
```typescript
const car1 = new Car(50, 5);

car1.run(10);   // 충분한 연료
car1.run(100);  // 연료 부족
car1.run(250);  // 연료 정확히 소진

car1.refuel(20); // 연료 보충
console.log("현재 연료:", car1.getFuel());
```

### 출력:
```
이동 거리: 10
남은 연료: 48
연료 부족
이동 거리: 250
남은 연료: 0
연료 보충됨. 현재 연료: 20
현재 연료: 20
```

## 🔐 캡슐화 포인트

| 요소       | 접근성        | 설명                          | 관련 메서드   |
|------------|---------------|-------------------------------|---------------|
| fuel       | private       | 차량의 현재 연료량            | getFuel()     |
| power      | private       | 차량의 연비 (1리터당 이동 거리)|               |
| run()      | public        | 주행 기능, 내부 로직 은닉      |               |
| refuel()   | public        | 연료 보충 기능 제공            |               |
