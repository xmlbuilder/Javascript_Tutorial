# 호이스팅
자바스크립트의 호이스팅은 변수와 함수 선언을 코드 실행 전에 메모리 상단으로 끌어올리는 동작입니다.  
함수 선언은 전체가 끌어올려지고, 변수는 선언만 끌어올려지며 값은 undefined로 초기화됩니다.

## 🔍 호이스팅(Hoisting)이란?
호이스팅은 자바스크립트 엔진이 실행 전에 변수와 함수의 선언을 해당 스코프의 최상단으로 끌어올리는 동작입니다.  
즉, 코드가 작성된 순서와 관계없이 선언된 함수와 변수는 먼저 메모리에 등록됩니다.

## 📌 함수 선언 vs 변수 선언 (Hoisting 비교)

| 구분           | 호이스팅 방식             | 초기값       | 호출 가능 시점       | 특징                          |
|----------------|---------------------------|--------------|----------------------|-------------------------------|
| `function`     | 전체 함수 정의가 끌어올려짐 | 함수 자체    | 선언 이전에도 가능    | 덮어쓰기 가능, 가장 마지막 선언이 유효 |
| `var` 변수     | 변수 이름만 끌어올려짐     | `undefined` | 선언 이전엔 오류 발생 | 값은 나중에 할당됨             |



## 🧠 예제 분석
```javascript
console.log(a()); // a
console.log(b()); // b
console.log(c()); // c

function a(){ return 'a'; }
function b(){ return 'b'; }
function c(){ return 'c'; }

var a;
var b;
var c;

console.log(a()); // a
console.log(b()); // b
console.log(c()); // c

function a(){ return 'a'; }
function b(){ return 'b'; }
function c(){ return 'c'; }
```    

### 실행 흐름
- 함수 선언문 a, b, c는 전체 함수 정의가 호이스팅됨.
- 변수 선언 var a, var b, var c는 변수 이름만 호이스팅, 값은 undefined로 초기화.
- 하지만 변수 선언이 함수 선언보다 나중에 실행되므로 함수가 덮어씌워지지 않음.
- 따라서 a(), b(), c() 모두 정상적으로 함수 호출됨.

### ⚠️ 주의할 점: 덮어쓰기(overwrite)
```rust
function sum(a, b) {
  return a + ' + ' + b + ' = ' + (a + b);
}
```
```rust
function sum(a, b) {
  return a + b;
}

console.log(sum(1, 2)); // 3
```

- 두 개의 sum() 함수 선언이 있을 경우, 마지막 선언이 이전 선언을 덮어씀.
- 호이스팅 시 두 함수 모두 끌어올려지지만, 마지막 선언이 메모리에 남음.
- 따라서 "1 + 2 = 3"이 아닌 3만 출력됨.

### 📌 핵심 요약
- 함수 선언문은 전체가 호이스팅되어 선언 전에도 호출 가능.
- 변수 선언은 이름만 호이스팅, 값은 undefined.
- 같은 이름의 함수가 여러 번 선언되면 마지막 선언이 유효.
- 호이스팅은 선언만 끌어올리고, 할당은 끌어올리지 않음.

- 자바스크립트의 실행 컨텍스트와 호이스팅은 디버깅과 코드 이해에 매우 중요합니다.
